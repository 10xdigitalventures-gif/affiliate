# Internationalisation (i18n) and RTL support

## Supported locales

| Locale | Language | Direction |
|--------|----------|-----------|
| `en` | English | LTR |
| `ar` | Arabic | RTL |
| `fr` | French | LTR |

## Adding a new language

1. Create `web/messages/<locale>.json` using `en.json` as a template.
2. Add the locale to the `locales` array in `web/lib/i18n.ts`.
3. If the language is RTL, add it to the `rtlLocales` list.
4. Open a PR — the CI axe-core job will also audit the new locale.

## RTL implementation notes

- Use `dir={locale === 'ar' ? 'rtl' : 'ltr'}` on the `<html>` element in
  `web/app/[locale]/layout.tsx`.
- Use Tailwind's `rtl:` variant for directional spacing (e.g. `rtl:mr-4`).
- Use `start` / `end` instead of `left` / `right` in CSS logical properties.
- Avoid absolute positioning based on `left:` — use `inset-inline-start`.
- Test with Arabic content as it is longer in some phrases and shorter in
  others than English.

## Cookie/header locale detection order

1. `NEXT_LOCALE` cookie (explicit user choice)
2. `Accept-Language` header (browser default)
3. Fall back to `en`
